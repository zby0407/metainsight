# 知衡品牌覆盖

该目录把上游 DeerFlow 前端转换为“知衡”产品界面，避免在每次升级上游镜像时手工重复改名。

构建 `Dockerfile.frontend-admin-overlay` 时会：

- 替换页面标题、欢迎语、侧栏名称、市场文案与登录页图形；
- 移除产品界面中的上游官网、GitHub、问题反馈和支持邮箱入口；
- 将“关于”页改为知衡产品说明；
- 把上游公开落地页重定向到知衡工作台；
- 避免金融数据中的单个 `~` 被误渲染为删除线，并增强来源链接的颜色、下划线、外链图标与键盘焦点；
- 扫描主要用户界面文件，若仍有上游品牌文案则中止构建。

Python 包名、数据库文件名和容器网络名属于运行时兼容接口，不在这里改名。第三方许可证与版权声明继续保留在部署材料中。

## 安全部署

生产服务器禁止直接执行前端构建。使用同目录下的
`deploy-frontend-safe.sh`：脚本会在本机生成 `linux/amd64` 镜像，再通过压缩流导入服务器，
服务器端只调用项目的 `deploy.sh start`（该模式不构建镜像）。切换前会保留当前镜像的回滚标签，品牌或
HTTP 健康检查失败时自动恢复旧版本。

脚本还会拒绝以下危险状态：生产机存在第二套 Snap Docker、Docker daemon 数量不为 1、
生产机上已有构建进程，或系统盘可用空间低于 2 GiB。

网关品牌覆盖使用 `deploy-gateway-safe.sh`，采用相同的本机构建、流式导入、无构建切换和
自动回滚规则。

## 收盘 DSA 调度

账户开启收盘自动 DSA 后，网关在工作日 `15:10`（`Asia/Shanghai`）开始确认行情。
优先使用包含当天日期的收盘日线；若日线发布延迟，默认等待 5 分钟后交叉核验实时行情：
实时行情的昨收必须等于最新日线收盘，并且完整 OHLCV 不能与上一交易日相同。只有通过
这组校验才会创建 DSA 任务，因此行情源延迟不会漏跑，节假日的陈旧行情也不会触发误跑。

等待时间可通过 `DSA_AUTOMATION_QUOTE_FALLBACK_MINUTES` 调整（0–60 分钟）。生产热修复
使用 `Dockerfile.gateway-dsa-hotfix-overlay` 叠加到当前生产网关镜像，只替换调度模块，
不会覆盖投资组合 Agent 或其他已有网关能力。
